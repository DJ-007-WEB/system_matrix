# SupplyChain Sentinel

Lightweight supply-chain visibility for small manufacturers: document ingestion, reconciliation, supplier performance, inventory runway, evidence-backed alerts, and human approval.

## Run
1. Copy `.env.example` to `.env`.
2. Run `docker compose up --build`.
3. Frontend: http://localhost:3000
4. API docs: http://localhost:8000/docs

The seeded demo works without an AI key. AI document extraction requires a configured provider key.
